# Sayi Oyunu
A game like wordle, but with numbers

Program 4 basamakli rakamlari birbirinden farkli bir sayi tutar. 
Bu sayiyi her hakkinizda rakamlari farkli 4 basamakli bir sayi girerek tahmin etmeye calisiniz.
. + degeri yerinde dogru olan rakam sayisini gosterir.
. - degeri sayida bulunan ama yeri dogru olmayan sayilari gosterir.
Bol sans!

The program picks a 4-digit number with all digits different.
Your goal is to guess this number by entering another 4-digit number with all digits different in each attempt.
The + value indicates how many digits are correct and in the correct position.
The - value indicates how many digits exist in the secret number but are in the wrong position.
Good luck!
